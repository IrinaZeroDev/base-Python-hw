### Краткая инструкция:

При старте программа просит ввести поисковый запрос.

Загружает страницу Википедии, показывает название.

Дальнейший выбор: листать параграфы (по одному), выбрать и перейти по внутренней ссылке, выйти.

Для перехода по внутренней ссылке выводится список первых 10 ссылок в статье.

Все операции через консоль, значения и номера выбираются вручную.

**Убедитесь, что у вас установлен Chrome и Chromedriver!**

В примере используется headless-режим; если хотите видеть браузер — удалите строку options.add_argument("--headless").
